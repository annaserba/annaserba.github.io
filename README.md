# Сайт-визитка Анны Сербы

Статический сайт из одного HTML-файла. Зависимостей нет, собирать нечего:
достаточно положить содержимое этой папки в репозиторий GitHub Pages.

```
annaserba-site/
├── index.html        — сама страница (текст, ссылки, разметка для поиска и ИИ)
├── assets/styles.css — оформление
├── robots.txt        — явное разрешение поисковым и ИИ-краулерам
├── llms.txt          — краткая справка о вас для ИИ-агентов
├── sitemap.xml       — карта сайта
├── CNAME.example     — пример файла для привязки своего домена
└── README.md
```

## Шаг 1. Выложить на GitHub Pages (бесплатно, 10 минут)

1. Войдите в аккаунт **`annaserba`** (тот, где 69 репозиториев и живая активность).
2. Создайте **публичный** репозиторий с именем ровно **`annaserba.github.io`**.
   Имя важно: именно оно даёт адрес `https://annaserba.github.io/`.
3. Загрузите в него всё содержимое этой папки (`index.html` — в корень, не во вложенную папку).
   Через веб-интерфейс: `Add file` → `Upload files`.
4. `Settings` → `Pages` → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → `Save`.
5. Через 1–2 минуты сайт откроется по адресу `https://annaserba.github.io/`.
   HTTPS включается сам, сертификат Let's Encrypt — бесплатно.

## Шаг 3. Привязать свой домен (когда решите)

Домен не меняет сайт — он только меняет адрес. Регистрируете `annaserba.ru`
(и `annserba.ru` редиректом) у российского регистратора, дальше:

1. `Settings` → `Pages` → `Custom domain` → вписать `annaserba.ru` → `Save`.
   GitHub сам создаст в репозитории файл `CNAME` (поэтому `CNAME.example` здесь — просто образец).
2. В DNS у регистратора для домена `annaserba.ru` — четыре A-записи на IP GitHub Pages:
   `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   (актуальные значения сверьте в документации GitHub Pages перед настройкой).
   Для `www` — CNAME на `annaserba.github.io`. Для `annserba.ru` — редирект на `annaserba.ru`.
3. Дождаться выпуска сертификата и включить **Enforce HTTPS**.
4. `Settings` → `Pages` → `Verified domains` — верифицировать домен, чтобы его не мог занять чужой аккаунт.

После привязки домена поменять адреса в этих местах:

- `index.html`: `canonical`, `og:url`, поле `url` и `sameAs` в JSON-LD;
- `sitemap.xml`: адрес в `<loc>`;
- `robots.txt`: строку `Sitemap:`;
- `llms.txt`: ссылки в разделах «Основное».
